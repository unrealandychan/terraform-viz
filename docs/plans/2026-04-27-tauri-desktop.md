# Tauri Desktop App Implementation Plan

> **For Hermes:** Use subagent-driven-development skill to implement this plan task-by-task.

**Goal:** Convert terraform-viz from a Next.js web app into a cross-platform desktop app using Tauri, keeping the existing React UI intact and replacing the Node.js backend services with Rust.

**Architecture:**
- **Frontend:** Keep existing React/Next.js UI as-is (Tauri embeds a WebView)
- **Backend:** Rust replaces Node.js microservices (`parser`, `pricing`, `comparison`, `llm`)
- **IPC:** Tauri `invoke()` commands replace `/api/*` HTTP routes
- **Storage:** `tauri-plugin-store` replaces `localStorage` for persistence

**Tech Stack:** Tauri 2.x · Rust · serde_json · reqwest · existing React/TypeScript UI

**Branch:** `feat/tauri-desktop`

**Pre-requisites (one-time env setup):**

### Task 6: Implement Rust parser

**Objective:** Parse Terraform plan JSON into GraphModel — port of `services/parser`.

**File:** `src-tauri/src/parser.rs`

```rust
use crate::types::*;
use anyhow::Result;

fn detect_provider(resource_type: &str) -> String {
    if resource_type.starts_with("aws_") { "AWS".into() }
    else if resource_type.starts_with("google_") { "GCP".into() }
    else if resource_type.starts_with("azurerm_") { "Azure".into() }
    else { "Other".into() }
}

fn detect_layer(resource_type: &str) -> String {
    let compute = ["aws_instance", "aws_lambda", "google_compute_instance",
                   "azurerm_virtual_machine", "aws_ecs_service", "aws_eks"];
    let storage = ["aws_s3", "aws_rds", "aws_dynamodb", "google_storage",
                   "google_bigquery", "azurerm_storage"];
    let network = ["aws_vpc", "aws_subnet", "aws_security_group",
                   "google_compute_network", "azurerm_virtual_network"];
    let data    = ["aws_glue", "aws_kinesis", "google_dataflow",
                   "google_pubsub", "aws_sqs", "aws_sns"];

    if compute.iter().any(|p| resource_type.starts_with(p)) { "COMPUTE".into() }
    else if storage.iter().any(|p| resource_type.starts_with(p)) { "DATA".into() }
    else if network.iter().any(|p| resource_type.starts_with(p)) { "NETWORK".into() }
    else if data.iter().any(|p| resource_type.starts_with(p)) { "DATA".into() }
    else { "OTHER".into() }
}

pub fn parse_plan(raw: &str) -> Result<GraphModel> {
    let plan: TerraformPlan = serde_json::from_str(raw)?;
    let mut nodes: Vec<GraphNode> = Vec::new();
    let mut edges: Vec<GraphEdge> = Vec::new();

    if let Some(changes) = &plan.resource_changes {
        // Build attribute map from planned_values for richer data
        let mut attr_map: std::collections::HashMap<String, serde_json::Value> =
            std::collections::HashMap::new();
        if let Some(pv) = &plan.planned_values {
            if let Some(rm) = &pv.root_module {
                if let Some(resources) = &rm.resources {
                    for r in resources {
                        if let Some(vals) = &r.values {
                            attr_map.insert(r.address.clone(), vals.clone());
                        }
                    }
                }
            }
        }

        for change in changes {
            // Skip no-op resources
            if change.change.actions == vec!["no-op"] { continue; }

            let action = match change.change.actions.first().map(|s| s.as_str()) {
                Some("create")  => "create",
                Some("delete")  => "delete",
                Some("update")  => "update",
                Some("replace") => "replace",
                _               => "no-op",
            };

            let attributes = attr_map
                .get(&change.address)
                .cloned()
                .or_else(|| change.change.after.clone())
                .unwrap_or(serde_json::Value::Object(Default::default()));

            let node = GraphNode {
                id: change.address.clone(),
                name: change.name.clone(),
                r#type: change.r#type.clone(),
                provider: detect_provider(&change.r#type),
                layer: detect_layer(&change.r#type),
                change_action: action.to_string(),
                attributes,
                dependencies: change.depends_on.clone().unwrap_or_default(),
            };

            // Build edges from dependencies
            for dep in &node.dependencies {
                edges.push(GraphEdge {
                    source: dep.clone(),
                    target: node.id.clone(),
                });
            }

            nodes.push(node);
        }
    }

    Ok(GraphModel {
        nodes,
        edges,
        terraform_version: plan.terraform_version,
        provider_counts: serde_json::Value::Object(Default::default()),
    })
}
```

```rust
fn attr_str(attrs: &Value, key: &str) -> String {
    attrs.get(key)
        .and_then(|v| v.as_str())
        .unwrap_or("")
        .to_string()
}

fn attr_f64(attrs: &Value, key: &str, default: f64) -> f64 {
```

## Phase 4 — Tauri Commands (IPC bridge replacing /api/* routes)

### Task 8: Wire up Tauri commands in main.rs

**Objective:** Expose `parse_plan`, `estimate_costs`, `open_file` as Tauri commands — replaces all `/api/*` Next.js routes.

**File:** `src-tauri/src/main.rs`

```rust
// Prevents additional console window on Windows in release
#![cfg_attr(not(debug_assertions), windows_subsystem = "windows")]

mod types;
mod parser;
mod pricing;

use tauri::Manager;

/// Command: parse a raw terraform plan JSON string → GraphModel JSON
#[tauri::command]
async fn parse_plan(raw: String) -> Result<types::GraphModel, String> {
    parser::parse_plan(&raw).map_err(|e| e.to_string())
}

/// Command: estimate costs for all nodes in a GraphModel
#[tauri::command]
async fn estimate_costs(
    nodes: Vec<types::GraphNode>,
) -> Result<Vec<serde_json::Value>, String> {
    let results = nodes
        .iter()
        .map(|node| {
            let est = pricing::estimate_cost(node);
            serde_json::json!({
                "id": node.id,
                "monthly": est.monthly,
                "breakdown": est.breakdown,
                "annual": est.monthly.map(|m| m * 12.0),
            })
        })
        .collect();
    Ok(results)
}

/// Command: open a .tfplan or .json file via native file dialog
#[tauri::command]
async fn open_plan_file(app: tauri::AppHandle) -> Result<Option<String>, String> {
    use tauri_plugin_dialog::DialogExt;
    let file = app
        .dialog()
        .file()
        .add_filter("Terraform Plan", &["json", "tfplan"])
        .blocking_pick_file();
    match file {
        Some(path) => {
            let content = std::fs::read_to_string(path.to_string())
                .map_err(|e| e.to_string())?;
            Ok(Some(content))
        }
        None => Ok(None),
    }
}

fn main() {
    tauri::Builder::default()
        .plugin(tauri_plugin_shell::init())
        .plugin(tauri_plugin_dialog::init())
        .plugin(tauri_plugin_fs::init())
        .plugin(tauri_plugin_store::Builder::default().build())
        .invoke_handler(tauri::generate_handler![
            parse_plan,
            estimate_costs,
            open_plan_file,
        ])
        .run(tauri::generate_context!())
        .expect("error while running tauri application");
}
```

### Task 9: Create Tauri IPC adapter

**Objective:** Add a thin adapter so the React UI can call Tauri commands instead of `/api/*` HTTP routes — zero changes to existing components needed.

**File:** `apps/web/src/lib/tauri-bridge.ts`

```typescript
// Detect if running inside Tauri desktop or in browser
const isTauri = typeof window !== "undefined" && "__TAURI_INTERNALS__" in window;

async function tauriInvoke<T>(cmd: string, args?: Record<string, unknown>): Promise<T> {
  const { invoke } = await import("@tauri-apps/api/core");
  return invoke<T>(cmd, args);
}

// ── Parse Plan ────────────────────────────────────────────────
export async function parsePlan(raw: string) {
  if (isTauri) {
    return tauriInvoke("parse_plan", { raw });
  }
  // Fallback: web mode → existing API route
  const res = await fetch("/api/parse", {
    method: "POST",
    headers: { "Content-Type": "application/json" },
    body: JSON.stringify(raw),
  });
  if (!res.ok) throw new Error(await res.text());
  return res.json();
}

// ── Open File (desktop only) ──────────────────────────────────
export async function openPlanFile(): Promise<string | null> {
  if (!isTauri) return null;
  return tauriInvoke<string | null>("open_plan_file");
}

// ── Estimate Costs ────────────────────────────────────────────
export async function estimateCosts(nodes: unknown[]) {
  if (isTauri) {
    return tauriInvoke("estimate_costs", { nodes });
  }
  // Web mode: pricing is done client-side already, this is a no-op
  return nodes;
}

export { isTauri };
```

```rust
    stream: bool,
}

#[derive(Serialize, Deserialize)]
struct ChatMessage {
    role: String,
    content: String,
}

#[tauri::command]
pub async fn chat(
    api_key: String,
    base_url: String,
    model: String,
    messages: Vec<serde_json::Value>,
    window: tauri::Window,
) -> Result<String, String> {
    let client = Client::new();
    let msgs: Vec<ChatMessage> = messages
        .iter()
        .map(|m| ChatMessage {
            role: m["role"].as_str().unwrap_or("user").to_string(),
            content: m["content"].as_str().unwrap_or("").to_string(),
        })
        .collect();

    let req = ChatRequest { model, messages: msgs, stream: false };
    let url = format!("{}/chat/completions", base_url.trim_end_matches('/'));

    let resp = client
        .post(&url)
        .bearer_auth(&api_key)
        .json(&req)
        .send()
        .await
        .map_err(|e| e.to_string())?;

    let body: serde_json::Value = resp.json().await.map_err(|e| e.to_string())?;
    let content = body["choices"][0]["message"]["content"]
        .as_str()
        .unwrap_or("")
        .to_string();
    Ok(content)
}
```
